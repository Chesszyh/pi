<a href="https://www.earendil.com" target="_blank" rel="noopener noreferrer">Earendil Inc</a> 是一家由 Armin Ronacher 和 Colin Daymond Hanna 于 2025 年创立的公益公司（Public Benefit Corporation）。Earendil 的宗旨，是通过打造软件和开放协议来增强人类的能动性；这些软件和协议能够弥合分歧与无知，并培育持久的快乐与理解。

为服务于上述目标，Earendil 今天很自豪地宣布几项重要消息：

<ul>
<li>收购开源项目 <a href="https://pi.dev" target="_blank" rel="noopener noreferrer">Pi</a>。Pi 由 Mario Zechner 编写，是当今软件工艺与品味的杰出范例。Pi 是 <a href="https://lucumr.pocoo.org/2026/1/31/pi/" target="_blank" rel="noopener noreferrer">OpenClaw 中的极简 agent</a>，也是一款被广泛采用的开源 coding agent（编码智能体）与 harness（智能体运行框架）。Mario 对开放性与软件工艺的坚持，与 Earendil 的创立宗旨高度契合。与此次收购同步，Mario Zechner 成为 Earendil 的重要股东和团队成员。</li>
<li><a href="https://lefos.com" target="_blank" rel="noopener noreferrer">Lefos</a> 于今天开放公开 Alpha 测试。Lefos 是我们迈向这样一种机器实体的第一步：它既应具备尽可能强的能力，也应当值得信赖。Lefos 通过电子邮件与你以及你的共同创作者沟通；邮件是一套由你掌控、也方便你与他人协作的技术栈。Lefos 帮助你的收件箱成为进行深度工作与沟通的命令行。用户现在可以在 <a href="https://lefos.com" target="_blank" rel="noopener noreferrer">Lefos.com</a> 加入候补名单。</li>
<li>Earendil 很自豪地宣布我们的早期支持者：Accel（Daniel Levine）、Balderton（Daniel Waterhouse），以及 n8n（Jan Oberhauser）、OpenClaw（Peter Steinberger）、Revolut（Vlad Yatsenko）、Sentry（David Cramer）和 Slack（Cal Henderson）等公司的创始人，此外还有许多人。我们感谢他们给予的信任与支持。</li>
</ul>
